# Mist Ressonance — Cooling Tower Telemetry & Analytics Dashboard

An industry-sponsored engineering dashboard designed for **Mist Ressonance** to monitor, visualize, and optimize cooling tower performance in real time. 

The platform aggregates live thermal and flow sensor data to compute critical thermodynamic efficiency metrics (Range, Approach, and Effectiveness %), detect anomalous operating conditions, and provide plant engineers with actionable operational insights.

### Key Features
- **Real-Time Thermodynamic Metrics:** Live tracking of Inlet/Outlet Water Temperatures, Wet Bulb Temperature (WBT), Cooling Range, Approach, and Tower Effectiveness.
- **Smart Alerting Engine:** Threshold-based fault detection for drift, high approach limits, and energy inefficiency.
- **Multi-Tower Aggregation:** Centralized operational overview with granular drill-downs for individual cooling cells.
